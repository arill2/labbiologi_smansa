## Register lengkap

### HIGH (Hard Gate)

1. **R-02 - Em dash** (`public/js/app.js:949`). "`... — Dipinjam: ...`". Belum diperbaiki.
2. **R-25 - Kontras teks tombol primary & nav aktif (terang)**. Putih di `#0d9488` = 3.74:1 (butuh 4.5:1); label nav aktif 11px = 3.74:1. Bentrok dengan identitas brand, butuh keputusan Anda.
3. **R-27 - Tidak ada loading state**. API ditunda 2.5s: `hasLoadingText=false`, `spinner=false`. Tabel tampak kosong lalu terisi.
4. **R-37 - Arah desain tidak tertulis**. Tidak ada `DESIGN.md`; dial ENERGY/RHYTHM/MOTION belum dideklarasikan.

12. **R-32 - 12 kontrol tanpa nama aksesibel**. Bukti: `filter-log-search`, `filter-barang-search`, `filter-pinjam-search`, `audit-log-search` (placeholder saja, bukan label), `audit-log-start`, `audit-log-end` (date), `import-csv-file` (file). Placeholder bukan pengganti label.

13. **R-32 - 5 modal tanpa semantik dialog**. Semua `.modal-backdrop` (`modal-barang`, `modal-pinjam`, `modal-kembalikan`, `modal-import`, `modal-password`): `role=null`, `aria-modal=null`, `aria-labelledby=null`. Screen reader tidak mengenali sebagai dialog.

14. **R-32 - Manajemen fokus modal salah**. Saat `modal-barang` dibuka, fokus tetap di trigger (`nav-peminjaman`), bukan masuk ke dialog. Tab tidak terjebak: urutan `nav-logs → btn-logout → theme-toggle → ... → barang-kode` (menembus konten latar). Setelah Escape, fokus tidak dikembalikan ke trigger (berakhir di `barang-nama`).

15. **R-32 - Sidebar off-canvas masih bisa difokus di mobile**. Pada 390px, 5 stop Tab pertama adalah item sidebar yang tak terlihat (`transform: translateX(-280px)`, tanpa `inert`/`aria-hidden`): `nav-home, nav-inventaris, nav-peminjaman, nav-logs, btn-logout`. Pengguna keyboard masuk ke kontrol tak kasat mata.

16. **R-27 - Tidak ada error state inline**. API `/api/barang` di-abort: `inlineError=false`, isi tabel hanya whitespace. Kegagalan hanya lewat toast sementara; setelah toast hilang tidak ada penjelasan atau tombol coba lagi.

17. **R-35 - Overflow horizontal pada zoom 200%**. `documentElement.scrollWidth=557` vs `innerWidth=390` (viewport efektif ~195px CSS). Konten tidak reflow, muncul scroll horizontal (WCAG 1.4.10).

21. **KEAMANAN (di luar aturan antislop, kritis)** - Kredensial admin default ditampilkan di halaman login (`public/index.html:41-44`): "Username: admin • Password: adminlab123". Siapa pun yang membuka halaman mendapat kredensial penuh. Hapus blok ini sebelum publikasi.

### MEDIUM (Purpose-Gate + aksesibilitas)

5. **R-10 - Glassmorphism > dosis**. `backdrop-filter: blur` di 4 permukaan: topbar `:337`, modal `:861`, sidebar `:1134`, bottom nav `:1161`. Batas 1-2.
6. **R-13 - Glow tersebar**. `--primary-glow` pada brand icon, tombol primary (`:646`, `:651`), login card, focus ring.
7. **R-01 - Gradient tanpa alasan tertulis**. Indigo→teal (`:154`, `:277`, `:1088`) dan glow radial teal+indigo login (`:1063`).
8. **R-29 - Palet 6 hue**. teal, indigo, emerald, cyan, merah, amber tanpa sistem terdaftar.
9. **R-19 - Animasi pulse tanpa henti**. `animation: pulse 1.5s infinite` (`:790`) pada stok menipis & TERLAMBAT (`app.js:438`, `:441`, `:795`).

18. **R-19 - `prefers-reduced-motion` diabaikan**. Tidak ada media query reduced-motion; `fadeIn` (`:402`), `slideIn` (`:1036`), `pulse` selalu jalan. Pengguna yang meminta gerak minimal tetap mendapat animasi.

19. **R-25 - Kontras non-teks border kontrol < 3:1**. 10 kontrol: border `#e2e8f0` pada terang = **1.23:1**; border `#24324a` pada gelap = **1.38:1**. Batas komponen UI 3:1 (WCAG 1.4.11). Bidang input nyaris tak terlihat.

20. **R-25 - Placeholder tema gelap < 4.5:1**. Placeholder pencarian = **3.85:1**; `filter-barang-stok-menipis` = **1.44:1** (hitam di latar gelap). Placeholder terang lolos.

22. **R-32 - Indikator fokus select lemah**. `.select-control:focus` hanya mengubah `border-color` (`:617`), tanpa ring, berbeda dari input yang punya `box-shadow` (`:983`). Indikator fokus 1px dan subtle, tidak memenuhi saran "lebih tebal dari 1px + kontras".

### LOW (Quality Locks)

10. **R-06 - Header tabel uppercase + tracking**. `.data-table th` `text-transform: uppercase; letter-spacing: 0.05em` (`:679`). Konvensional, bukan pelanggaran, hanya catatan.
11. **Copy - Emoji dekoratif**. "⚡" (`app.js:934`) dan "📅" (`app.js:953`).
24. **Dependency eksternal**. `@import` Google Fonts (Outfit + Plus Jakarta Sans) di `style.css:1`, render-blocking dan memanggil pihak ketiga. Ada fallback system font, jadi aman saat offline.

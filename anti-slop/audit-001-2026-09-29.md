# Audit Anti-Slop UI 001 - 2026-09-29

Sistem Inventarisasi Lab Biologi SMANSA Pinrang. Audit Mode 2 (setelah jadi). Ruang lingkup: UI dan copy di `public/index.html`, `public/css/style.css`, `public/js/app.js`, diperiksa pada mobile (320/390/768) dan desktop (1440), tema terang dan gelap.

Metode: inspeksi kode + pengukuran terprogram (Playwright/chromium): overflow horizontal, tap target, kontras WCAG, state kosong/muat/error.

## Ringkasan

- Hard Gate (HIGH): 4 temuan (1 sudah diperbaiki sesi ini, 3 tersisa)
- Purpose-Gate (MEDIUM): 5 temuan
- Quality Locks (LOW): 2 temuan
- Tidak ada temuan: klaim/testimoni/statistik fiktif, navbar mati, FAQ template, ilustrasi generik, background grid, arrow dekoratif.

## Resolved in this session (bukan temuan aktif)

- R-03 Mobile: layout jebol sampai ~1105px di tab Inventaris (`.main-wrapper` tanpa `min-width:0`) sudah diperbaiki. Modal "Tambah Barang" tidak bisa scroll (form pembungkus tanpa aturan flex + `max-height` vh) sudah diperbaiki. Topbar, filter tanggal Log, dan paginasi Log overflow sudah diperbaiki. Terverifikasi: 12 kombinasi device/tab tanpa overflow.
- R-03 Tap target: seluruh tombol/select kini minimal 44px di mobile.
- R-25 (sebagian): badge status dan timestamp log naik dari ~1.9-3.3:1 ke >=4.5:1 lewat token per tema.

## Temuan

### HIGH (Hard Gate)

1. **R-02 - Em dash di teks** (`public/js/app.js:949`). String "`... — Dipinjam: ...`" memakai em dash. Ganti dengan titik dua, koma, atau tanda kurung.

2. **R-25 - Kontras tombol primary & label nav aktif (tema terang)**. Teks putih di atas brand teal `#0d9488` = **3.74:1** (butuh 4.5:1 untuk teks 14px weight 600); label bottom-nav aktif 11px juga 3.74:1. Terdampak: "Tambah Barang Baru", "Peminjaman Baru", "Simpan Data", dan label nav aktif. Di tema gelap ambang ~4.5:1 (pas-pasan). Perlu warna teks/bg khusus agar lolos AA di dua tema.

3. **R-27 - Tidak ada loading state**. Pengambilan data (daftar barang, peminjaman, log) hanya punya empty state dan error berupa toast. Tidak ada indikator muat (spinner/skeleton) saat fetch, sehingga tabel tampak kosong lalu tiba-tiba terisi.

4. **R-37 - Arah desain tidak tertulis**. Tidak ada `DESIGN.md` atau dokumen arah gaya; dial ENERGY/RHYTHM/MOTION tidak dideklarasikan. Palet bernama ("Emerald Lab Tech") dan dua typeface (Outfit + Plus Jakarta Sans) sudah konsisten, tetapi tanpa arah tertulis hasil ini secara aturan berlabel "draft tanpa arah". Aksi: tulis `DESIGN.md` singkat, atau konfirmasi dial.

### MEDIUM (Purpose-Gate)

5. **R-10 - Glassmorphism melebihi dosis**. `backdrop-filter: blur` dipakai di 4 permukaan: topbar (`style.css:337`), backdrop modal (`:861`), sidebar (`:1134`), bottom nav (`:1161`). Batas 1-2 elemen. Sisakan glass di topbar + bottom nav, jadikan sidebar/modal solid.

6. **R-13 - Glow tersebar**. `--primary-glow` muncul di brand icon, tombol primary (`:646`, `:651`), login card, dan focus ring. Pilih 1-2 momen saja (mis. focus ring + satu CTA utama).

7. **R-01 - Gradient tanpa alasan tertulis**. Gradient indigo ke teal (`:154`, `:277`, `:1088`) dan glow radial teal+indigo di background login (`:1063`). Bukan blue-purple, tetapi perlu alasan hierarki/identitas tertulis atau diganti solid.

8. **R-19 - Animasi pulse tak berujung**. `animation: pulse 1.5s infinite` pada badge (`:790`) dipakai untuk stok menipis dan status TERLAMBAT (`app.js:438`, `:441`, `:795`). Gerak terus-menerus tanpa trigger pengguna; badge statis berwarna sudah cukup, atau pulse hanya saat pertama tampil.

9. **R-29 - Palet melebihi batas core+accent**. Warna aktif: teal, indigo, emerald, cyan, merah, amber (6 hue). Sebagian semantik (danger/warning/success) yang wajar, tetapi tanpa sistem terdaftar. Tetapkan 2-3 core + 1 accent dan perlakukan status sebagai semantic tokens.

### LOW (Quality Locks)

10. **R-06 - Header tabel uppercase + tracking**. `.data-table th` memakai `text-transform: uppercase; letter-spacing: 0.05em` (`:679`). Konvensional dan ringan, bukan pelanggaran, tetapi catat agar tidak merembet ke label lain.

11. **Copy - Emoji dekoratif di teks body**. "⚡" (`app.js:934`) dan "📅" (`app.js:953`). Minor; hapus atau ganti kata biasa.

## Pass (bukan temuan)

- R-24 Navbar: 4 item nav mobile + 4 item sidebar semua mengarah ke tab yang ada (`tab-home/inventaris/peminjaman/logs`). Tidak ada link mati.
- R-26 Kontrol: semua tombol/form berfungsi; modal bisa ditutup Escape (ditambahkan sesi ini); body terkunci saat modal buka.
- R-34/R-21 Tema: toggle terang/gelap berfungsi di dua tema (terverifikasi), default terang (bukan dark paksa).
- R-15/R-16 Copy: CTA spesifik ("Tambah Barang Baru", "Simpan Data", "Konfirmasi Peminjaman"), tanpa buzzword AI.
- R-17/R-18/R-36/R-38: tidak ada statistik, testimoni, atau klaim tanpa sumber (ini aplikasi internal).
- R-04 Ikon: SVG relevan (matahari tema, gembok password, menu, dokumen log). Tidak ada sparkle/star/orb.
- R-07/R-08/R-22/R-28: tanpa background grid, tanpa arrow dekoratif, tanpa ilustrasi generik, tanpa FAQ template.
- R-03/R-11: radius konsisten (8/12/16/full), tap target >=44px, tanpa overflow horizontal (setelah perbaikan).
